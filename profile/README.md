## What Is EMCO Ping Monitor

EMCO Ping Monitor is a ping-only helper. It does not inventory hardware or read event records. EMCO Ping Monitor uptime, EMCO Ping Monitor latency, and EMCO Ping Monitor packet loss are three views of the same simple question: does this host you manage answer, how slow is the answer, and are answers missing? That is the right tool when a small office or a classroom mostly needs to know that a gateway, a server, or a remote site is reachable.

EMCO Ping Monitor outage alert tells you when the answers stop. EMCO Ping Monitor host chart lets you see whether latency climbed before the outage or whether loss was the real story. You aim it at hosts on networks you administer, or at addresses your organization told you to watch. A lesson that depends on a lab server is a good reason to look before the class walks in.

Keep the list short. A gateway, a file server, and maybe one remote office address are enough. EMCO Ping Monitor uptime and EMCO Ping Monitor host chart will be readable. EMCO Ping Monitor latency and EMCO Ping Monitor packet loss explain a “slow but up” complaint. EMCO Ping Monitor outage alert covers the moment it is not up at all.
